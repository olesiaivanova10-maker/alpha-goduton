# Альфа Хак — новостная аналитика

Сервис превращает новости и аналитические материалы Альфа-Банка в персонализированные бизнес-инсайты для руководителей компаний.

## Структура решения

```text
.
├── backend/                 # Данные, профиль компании и API
│   ├── app/
│   │   ├── main.py          # FastAPI endpoints
│   │   ├── data_loader.py   # Загрузка CSV один раз при старте
│   │   ├── company_context.py# Профиль, группа и контрагенты
│   │   └── schemas.py       # Контракты API
│   ├── data/                # CSV кейса (не коммитить реальные файлы)
│   ├── requirements.txt
│   └── Dockerfile
├── agent/                   # Агентная логика (зона коллеги)
│   └── README.md
├── frontend/                # Интерфейс Альфа-Бизнеса (зона коллеги)
│   └── README.md
├── .env.example
└── README.md
```

## Что такое функция и API

Функция `get_company_context("U123")` вызывается внутри Python-приложения. API — это HTTP-обёртка над той же функцией: фронтенд или отдельный агент обращается к `GET /companies/U123/context`. Данные остаются на сервере; модели передаётся только описание инструмента, а не исходные CSV.

## Быстрый запуск backend

```bash
cd backend
python -m venv .venv
source .venv/bin/activate       # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

После запуска:

- API: http://localhost:8000
- Swagger: http://localhost:8000/docs
- пример: `GET /companies/U123/context`

Положите в `backend/data/` файлы `df_Uid_data_hack.csv`, файл связей физических лиц и файл платежей. Точные имена можно задать через `.env`.

## Контракт между backend и агентом

Backend возвращает `company_context`: отрасль, регион, масштаб, банковские продукты, группу компаний, связанные лица и агрегированные связи по платежам. Агент добавляет новости и аналитику Альфа-Банка и возвращает инсайт с отдельными фактами, гипотезами, рекомендациями и `source_ids`.

Нельзя выдавать гипотезу за факт. Для каждого ключевого вывода должны сохраняться источники и признаки компании, повлиявшие на результат.

## Тестовый сценарий

1. Вызвать `GET /health`.
2. Вызвать `GET /companies/{SYNTHETIC_U}/context`.
3. Передать JSON в агент.
4. Проверить, что в ответе агента отдельно указаны факты, позиция банка, гипотезы, риски и источники.

Реальные данные кейса и секреты не добавляются в Git. Используйте `backend/data/*.example.csv` для синтетического smoke-теста.
