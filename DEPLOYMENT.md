# Общий стенд команды

- Код и данные на сервере: `/opt/alpha-hack`.
- Запуск: `cd /opt/alpha-hack && mkdir -p backend/data/reports && docker compose up -d --build --wait`.
- Состояние: `docker compose ps`; журнал: `docker compose logs --tail=80 backend`.
- `.env` содержит ключи только на сервере; не добавлять в Git.
- SQLite с карточками и обратной связью и кеш новостей находятся в томе `alpha-hack_backend_storage`.
- Не выполнять `docker compose down -v`: это удаляет постоянные данные.
- PDF, OCR-индексы и CSV подключаются из `data_alfbnk/` и `backend/data/`.
- Внешний nginx принимает HTTPS и требует пароль команды; контейнеры доступны только через localhost.
- Пока домен отсутствует, используется временный самоподписанный сертификат. После подключения домена заменить доверенным сертификатом.
- Последняя версия доставлена архивом из локальной интеграционной ветки. Перед командными обновлениями опубликовать изменения кода в GitHub без локальных секретов и больших данных.
- Анализ использует BackgroundTasks: перезапуск во время генерации прерывает текущую работу. Обновлять после завершения активных запросов.

## Журнал разработчика

Страница `/api/developer` использует тот же пароль команды. API: `/api/developer/news?company_id=U_14366&role=CFO&status=rejected&limit=50&offset=0`. История: `/api/developer/news/{news_id}/history?company_id=U_14366&role=CFO`.

Таблицы `journal_news`, `journal_state`, `journal_history` находятся в существующей SQLite `insights.db` постоянного тома. Статус зависит от компании и роли. Первоначальная загрузка восстанавливает каталог из RSS-кеша и существующие опубликованные карточки; старые отказы задним числом не восстанавливаются. Просмотр не вызывает модели. После перезапуска незавершённая обработка отмечается ошибкой. Лимиты расходов и автоматическая очередь этим обновлением не добавляются.
